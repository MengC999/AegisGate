# Changelog

## 3.1.0 — public-source preparation

- 整理内容安全网关、批量治理、审计与运营工作台的公开源码。
- 统一玻璃卡片与导航，主信息白色、辅助信息浅灰。
- 使用原创 SVG 替代未核实授权的照片，保留背景切换。
- ONNX 权重移至独立模型资产，新增大小与 SHA-256 校验下载器。
- 排除本地数据库、日志、缓存、项目报告及专利材料。
- 新增 GitHub Actions、问题模板、贡献与部署说明。
- 补充仅标准库启动路径、发行包验证工具、维护范围与源码加模型配套说明。
- 打包排除私人密钥文件、数据库、私人报告、专利材料与外部模型；验证两版模型元数据，拒绝损坏资产。
- 新增无需在线模型资产的源码打包 CI 检查；浏览器 E2E 断言同步到原创 SVG 背景。

代码版本以 VERSION 与运行时 `__version__` 的 3.1.0 为准；桌面工作目录名称不作为发行版本证据。此条目不表示 Release 已发布。
