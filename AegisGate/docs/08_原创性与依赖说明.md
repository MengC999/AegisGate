# 项目来源与依赖说明

## 工程来源

AegisGate 在原有“大模型过滤”原型上持续扩展，形成输入输出网关、多轮关联判定、证据解释与安全运营工作台。开源版权署名为 M4wwtr4c3 and contributors，代码适用 [Apache-2.0](../LICENSE)，版权告知见 [NOTICE](../NOTICE)。原型之外的第三方来源分别保留其许可证和归属。

## 运行与模型

后端为 Python，前端使用浏览器原生 HTML/CSS/JavaScript。NumPy 和 ONNX Runtime 支持本地 CPU 分类器；训练和导出依赖仅在显式安装 `requirements-training.txt` 时使用。推荐环境和复现步骤见 [测试说明](testing.md)。

ONNX 分类器是 `hfl/rbt3` 的微调衍生物，固定来源、revision、许可证、修改说明和校验信息保存在模型目录中。权重通过独立 Release 分发。合成训练和评测数据保留其 CC BY-4.0 许可。它们不与代码许可证混同。

默认 provider 为 Mock；启用云端 DeepSeek 或 OpenAI-compatible 服务需显式配置。可选本地 DeepSeek 与 ONNX 分类器是不同组件，安装与许可说明见 [本地模型部署](local-deepseek.md)。
