# 轻量语义分类器模型卡

- 模型名称：AegisGate Safety NB v2
- 模型类型：中文字符 bigram/trigram 与英文数字词元的多项式朴素贝叶斯
- 训练入口：`python scripts/train_classifier.py`
- 训练数据：`data/training_data_v2.json`
- 运行依赖：Python 标准库
- 使用目的：作为规则层之后的辅助语义信号，不单独做最终处置
- 不适用范围：不能替代人工复核、法律判断或通用大模型安全对齐
- 隐私说明：训练数据为项目自建合成短文本，不含真实个人数据
- 已知限制：小样本模型对新表达、方言和跨语言文本的泛化能力有限；系统通过规则、上下文校准和人工复核共同降低风险

模型文件保存数据集 SHA-256 摘要，便于复现实验与确认训练数据版本。
