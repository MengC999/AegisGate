# AegisGate 前后端便携运行包

适用于 Windows 10/11 的 x64 电脑。内置 Python 3.12.10、后端依赖和 CPU 内容检测模型，无需安装 Python、Node.js、数据库或 GPU，也无需联网下载依赖。

## 启动

1. 把整个 ZIP 解压到可写目录，例如 `D:\AegisGate`，不要在压缩包内直接运行。
2. 双击 `启动.bat` 或 `start.bat`，等待浏览器自动打开。
3. 默认地址为 `http://127.0.0.1:8765`。如果端口已占用，启动窗口会显示自动选择的新端口。
4. 保持启动窗口打开。关闭窗口或按 Ctrl+C 即可停止服务。

首次运行自动在 `runtime/` 中创建 SQLite 数据库与审计数据。再次启动会保留这些数据。迁移使用后的数据时，请先关闭服务，再复制整个目录。

## 包含内容

- `web/`：前端 HTML、CSS、JavaScript、图片和本地图表/图标库。
- `src/`：Python 后端源代码。
- `config/`：运行配置和安全策略。
- `data/`：运行词库与业务演示初始数据。
- `models/`：后端使用的 ONNX 检测模型及辅助分类器。
- `.runtime/python/`：独立 Python 环境和全部运行依赖。
- `scripts/`：启动、自检及模型检查脚本。

本包不含项目报告、PPT、截图、训练数据、测试资料、历史运行数据、DeepSeek/Ollama 服务或大型生成模型。模型目录中的来源、许可证和校验所需文件予以保留。

## 默认模式

内容检测使用真实的本地 ONNX CPU 模型；对话生成使用项目原有的离线 Mock。此包不提供本地 DeepSeek 文本生成。如需真实生成服务，可另行配置 `config/api_config.json` 中的 provider、API 地址和模型，并在启动终端设置其指定的密钥环境变量。程序不会读取 `.env` 文件。

## 自检及排查

双击 `check.bat`，通过时显示 `PASS`。自检覆盖页面文件、后端健康、ONNX 模型、检测接口、Mock 对话和新建 SQLite 数据库，测试数据放在临时目录。

文件夹必须完整解压，包含 `.runtime` 目录；建议预留 1 GB 可用磁盘空间。若无法启动，请查看启动窗口或自检窗口的具体错误。此内置运行环境不适用于 macOS、Linux、32 位 Windows 或原生 Windows ARM64。

## 校验

`MANIFEST.sha256` 列出了交付时各文件的 SHA-256。配置、词库或其他文件经用户修改后，摘要会相应变化。包外的 `.zip.sha256` 可用于核验压缩包复制前后的完整性。
