# 数据集与模型说明

## 1. 第二层模型与官方四类

本地第二层是微调并导出的五分类 ONNX 编码器模型。源码保存元数据和许可证，权重从独立 Release 安装（见根目录 README）。标签和展示映射固定如下：

| 模型标签 | 官方口径 | 引擎内部映射 | 定义摘要 |
|---|---|---|---|
| `normal` | 正常 | 无 | 不属于官方四类的正常文本 |
| `sexual` | 色情 | `sexual` | 色情内容、色情资源传播或相关诱导 |
| `violence` | 暴力 | `violence` | 暴力威胁、伤害实施、武器和血腥虐杀 |
| `advertising` | 广告 | `fraud` | 营销推广、导流、促销返利、外链和商业联系方式 |
| `sensitive_speech` | 敏感话术 | `sensitive_speech` | 提示注入、违法实施、仇恨歧视、自伤诱导及需要复核的敏感表达 |

官方四类是 Web、API、统计和评测的一级口径；九类内部风险能力继续保留，二者不是同一个标签集合。映射和标签顺序固化在 `models/official_four_onnx_v2/labels.json`。

## 2. 上游来源、许可和资产校验

- 基础编码器：`hfl/rbt3`，来源 <https://huggingface.co/hfl/rbt3>。
- 固定 revision：`0aa0527ff4170f29e1dfd3eb6ef60dc67e1bf75c`。
- 上游权重 SHA-256：`3e04f7477f55dffce2a2fbc4d0ba35068415162a9e92e3d5cc74a49781ba4eb0`。
- 许可证：Apache-2.0；模型卡、许可证、来源和修改说明随目录保存。
- 交付 ONNX：`154006588` bytes（约 146.87 MiB），SHA-256 `023e11ba9bef71b5e285e0f720bef4ea72aeeaf5e136f935abdeadf5cfc86710`。
- `models/official_four_onnx_v2/SHA256SUMS` 覆盖 ONNX、词表、标签、tokenizer 配置、模型卡、许可证、来源和训练摘要。

该文件是基础编码器加五分类线性头的微调导出结果，不是规则、常量输出或模拟模型。普通启动不会联网下载模型。

## 3. 数据治理与切分

`data/semantic_classifier_v2/` 是项目组自建合成与防御性改写文本，许可证 CC BY-4.0，不含真实对话或真实个人数据。五个标签各有 `100` 条训练、`20` 条验证和 `50` 条测试样本，合计 `850` 条；`data/semantic_classifier_v2/dataset_manifest.json` 记录每个文件的 SHA-256、来源和切分规则。

切分按 `family_id` 与 `source_batch` 分组隔离，在训练前封存测试集。自动去重使用 NFKC、小写、CJK/字母数字指纹和跨切分相似度；精确重复、家族泄漏、来源批次泄漏均为 `0`，人工复核候选单独记录。手机号、邮箱和身份证格式检查为 `0` 命中。模型训练、验证和最终测试不混用。

另有 `data/e2e_holdout_v1/` 的冻结端到端集，200 条，专用于网关级回归，不参与模型训练或阈值调参。其数据卡和 SHA-256 与评测报告一并保存。

## 4. 训练、导出与运行依赖分离

训练/导出入口为 `scripts/train_export_semantic_onnx.py`，仅在显式安装 `requirements-training.txt` 时使用 PyTorch、Transformers、ONNX 和固定上游来源。最终演示只安装 `requirements.txt`，即 `numpy==2.2.6` 与 `onnxruntime==1.23.2`；运行时仅使用 `CPUExecutionProvider`，不需要训练框架。

模型状态定义：

- `ready`：校验、标签、结构、CPU 加载和实际推理均通过。
- `unavailable`：模型文件或运行依赖缺失。
- `invalid`：校验、结构、加载或推理异常。

非 `ready` 不产生伪造 `pretrained_onnx` Evidence；规则层和 `naive_bayes` 辅助证据仍可运行。高风险规则可以直接拦截，其余文本进入第二层语义判断。

## 5. 实际评测

运行命令：

```text
Windows: python scripts/evaluate_onnx_classifier.py
```

保留的历史 v2 回归报告记录：测试 `250` 条，Accuracy `0.94`，Macro-F1 `0.939255`；原始分类器违规拦截率 `0.99`，正常误判率 `0.12`，其中 `sensitive_speech` recall `0.82`。阈值证据与混淆矩阵见 `reports/semantic_model_evaluation_v2_regression.json`。这些是模型层历史回归指标，不替代当前源码重新执行的评测，也不能代表开放环境准确率。

历史网关冻结端到端集 `200` 条报告记录：违规拦截率 `0.99`、正常文本误处置率 `0.02`、`TP=99 / FP=2 / FN=1 / TN=98`。结果仍有漏拦和误处置，不能宣称零误判或生产级准确率。

## 6. 辅助模型与限制

`training_data_v2.json` 与 `models/safety_classifier_v2.json` 对应字符 bigram/trigram Naive Bayes，仅作为 `naive_bayes` 辅助证据，不冒充预训练模型。系统目前只处理文本；对新表达、长上下文、多模态、真实业务分布和人工标注一致性的泛化仍需授权盲测。数据或模型升级必须同步保留来源、许可证、隐私检查、版本、SHA-256 和可重复报告。
