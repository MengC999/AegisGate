# 故障排查

## Python 命令不存在

安装 CPython 3.12 并创建虚拟环境。Windows 激活后执行 `python --version`，正式验收应显示 `Python 3.12.x`。不要修改核心脚本来绑定 `py -3` 或固定解释器路径。

## 环境检查提示不是正式基线

当前解释器不是 Python 3.12。Python 3.10、3.11、3.13 可用于兼容性检查，但不能作为统一正式验收结果；切换到 3.12 虚拟环境后重新运行 `scripts/environment_check.py --strict-baseline`。

## 8765 端口被占用

```powershell
python -m src.aegisguard serve --port 8766
```

然后访问 `http://127.0.0.1:8766`。

## 页面打开但接口失败

不要直接双击 `web/index.html`；必须通过 Python 服务访问。检查终端是否仍在运行，并访问 `/api/health`。

## 中文乱码

终端字体需支持中文。跨平台验收对子进程启用 UTF-8；JSON 与 Markdown 均为 UTF-8，CSV 为 UTF-8 with BOM，便于 Excel 打开。

## 模型未更新

运行 `python scripts/train_classifier.py`。模型热加载依据文件修改时间，正在运行的服务无需重启；如文件系统时间分辨率异常，可重启服务。

## 词库修改无效

先用 `python -m src.aegisguard words list` 检查类别与词条。JSON 必须有效，推荐通过 CLI 或 API 修改，避免手工破坏格式。

## 审计链校验失败

不要继续追加或删除证据。复制 `runtime/audit.jsonl` 到受控位置，记录失败行号并调查篡改或写入中断。演示环境确认无须保留后，可停止服务并重新创建空运行目录；生产环境不得用清空日志掩盖异常。

## 真实模型连接失败

确认 `provider=deepseek`、HTTPS URL、模型名、超时配置，以及当前进程已显式设置 `DEEPSEEK_API_KEY`。程序不读取 `.env` 或 `.env.local`。先访问 `/api/v1/model/status`：`configured` 只表示配置完整，不代表公网一定可达；`unavailable` 表示配置或密钥缺失。

运行 `scripts/deepseek_smoke_test.py` 只会在显式设置密钥后发出一个无敏感请求。失败时检查 DNS、TLS、代理、账户余额和 DeepSeek 服务状态。系统不会自动重试或切换 Mock，也不会在响应和日志中返回异常详情或密钥。

## 真实模式提示 mock_output 不可用

这是预期安全限制。`mock_output` 只能用于默认离线 Mock 演示；DeepSeek 或 OpenAI-compatible 模式必须使用真实上游响应，随后由网关执行输出复检。

## 一键验收失败

先检查终端中第一个失败的命令，并按 [测试说明](testing.md) 分别运行单元测试、ONNX 自检和启动健康检查。完整测试需要先安装开发依赖及 v1/v2 权重：`python scripts/download_models.py --model all`。

平台验收脚本生成的报告只代表该次实际运行；源码不附带旧的整机验收报告。保留失败日志用于定位，不要将历史评测数字作为当前环境通过的依据。

## ONNX 模型 unavailable

运行 `python scripts/download_models.py --model v2` 安装默认分类器，随后运行 `python scripts/download_models.py --verify-only` 检查文件。如果 Release 资产暂不可访问，可将可信资产下载到本地后用 `--source-dir <资产目录>` 安装；下载器会验证大小和 SHA-256。缺少权重时规则与辅助分类器仍可运行，完整语义检测不会标为就绪。
