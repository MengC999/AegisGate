# 使用与数据边界

AegisGate 面向内容安全研究、教学演示和经过授权的系统测试。测试数据由合成样本组成，不应替代真实业务分布下的评测。本说明介绍部署与研究边界，不增加 Apache-2.0 以外的代码许可条件。

## 隐私与留存

默认审计不保存完整对话原文。接入实际业务前，应配置访问权限、脱敏、加密、备份、留存期限和删除机制。真实数据测试须取得相应授权，并仅收集完成任务所需的信息。不要将真实对话、访问令牌或业务数据库提交到公开仓库。

## 人工复核

`review` 表示需要进一步核验，不是关于用户违法或违规的最终结论。检测可能误报或漏报，重要处置应保留人工复核、申诉入口和误报纠正机制。系统不提供医疗、法律或执法结论。

## 防御测试

对抗样本用于在受控环境下验证过滤器。调用外部模型、测试第三方服务和处理个人信息时，应遵守适用法律、服务条款及系统所有者的授权范围。项目默认测试使用 Mock 和本地 Fake Server。

## 支持性响应

`support` 路径提供面向求助表达的通用支持性建议，不是医疗服务。业务接入时应由合适的专业人员审核地区相关资源与响应策略。

生产部署能力与认证限制见 [部署说明](deployment.md)。发现代码漏洞时请按 [安全说明](../SECURITY.md) 私密报告。
